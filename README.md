# EyeSee

*Though I was blind, now I see.*

Eyeglass-matching software for the West Haven Eyeglass Ministry. Enter a
patient's prescription and EyeSee finds the closest match in your inventory
of donated glasses.

## Download

**[⬇ Get the latest version](../../releases/latest)**

| Your computer | Download the file ending in |
|---|---|
| Windows | `EyeSeeSetup-<version>.exe` |
| Mac | `EyeSee-<version>.dmg` |

---

## Installing on Windows

1. Download the `EyeSeeSetup-….exe` file from the latest release.
2. Double-click it.
3. **You will see a blue "Windows protected your PC" box.** This is normal —
   see below.
4. Follow the installer. When it asks, "Install for all users" needs an
   administrator password; "Install for me only" does not. Either is fine.

### "Windows protected your PC"

Windows shows this for any program it hasn't seen many times before. It does
**not** mean anything is wrong with the file.

> Click **More info**, then **Run anyway**.

That's it. If you don't see "Run anyway", click "More info" first — it's
hidden until you do.

## Installing on a Mac

1. Download the `EyeSee-….dmg` file from the latest release and
   double-click it.
2. Drag **EyeSee** onto the **Applications** folder shown in the window.
3. The first time you open it: **right-click** the EyeSee icon and choose
   **Open**, then click **Open** in the box that appears.

That right-click is only needed the first time. Double-clicking the first
time gives an unhelpful "cannot be opened" message instead.

## Where your data is kept

Everything lives in one folder:

- **Windows:** `Documents\EyeSee\`
- **Mac:** `Documents/EyeSee/`

That folder holds your glasses inventory, your settings, and dated backups
that EyeSee makes for you automatically. **Uninstalling EyeSee does not
delete it** — your inventory is safe.

To move to another computer, or to keep a copy somewhere safe, use
**Settings → Information → Export Inventory** and keep the file it makes.

## Updating

Download the newer installer and run it over the top. Your inventory and
settings are kept — the installer only replaces the program itself.

## Getting help

There's a **?** button at the top of every screen explaining what that screen
does and how to use it.

If something goes wrong, note what you were doing at the time and contact
Nathan. If it's a printing problem, the file
`Documents\EyeSee\print_diagnostics.txt` is useful to include.
